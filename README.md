# Jam Packed visuals

Interactive visuals for events: TouchDesigner as the live engine, with everything
that matters (shaders, presets, logic) kept as plain text files in this repo.

- `docs/tech-plan.md` the overall plan
- `playground/GUIDE.md` start here: Kinect setup and the reactive shader playground
- `shaders/` GLSL looks, each linked live into TouchDesigner
- `presets/looks.json` named looks (keys 1 to 9 in the playground)
